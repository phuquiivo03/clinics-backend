# linics-management-backend

# Getting Started

1. Clone this repository
2. Install dependencies

   ```bash
   bun install
   ```

   or

   ```bash
   bun install
   ```

3. Run project

   ```bash
   bun run dev
   ```

   or

   ```bash
   npm run dev
   ```

This project was created using `bun init` in bun v1.2.5. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.
